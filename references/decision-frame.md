# Decision Frame

Begin with the decision, not the idea description.

Capture: decision, owner, deadline/horizon, geography, project type, capital at risk,
funding mode, minimum acceptable outcome, constraints, and explicit non-goals.

Use this form:

> Should [owner] commit [capital/resources] to [project] in [jurisdiction] over
> [horizon], given [constraints], if success requires [threshold]?

If a threshold is missing, create a provisional `ASSUMPTION` and mark it for confirmation.

State the market boundary by customer, job/problem, geography, category, channel and horizon.
A vague boundary produces an unfalsifiable TAM.
