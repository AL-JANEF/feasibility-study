# Financial Model

Model in order: revenue drivers, capacity, variable cost/COGS, payroll/fixed OPEX, CAPEX, working capital,
applicable sourced tax/zakat treatment, financing/debt service, cash flow, balance-sheet effects where relevant,
then scenarios and sensitivity.

Core outputs when applicable: revenue, gross/contribution margin, EBITDA/operating profit, free cash flow,
peak funding need, break-even, runway, payback, ROI, NPV, IRR, DSCR, LTV/CAC.

Every material input gets an assumption ID, value/range, unit, basis, evidence IDs, confidence, owner,
validation plan, and affected outputs.

The bundled engine is mechanical only; it never invents projections.
