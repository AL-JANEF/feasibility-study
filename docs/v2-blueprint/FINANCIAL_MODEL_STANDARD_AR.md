# Feasibility V2 — معيار النموذج المالي

## الجداول الإلزامية
Assumptions / Timeline / Demand / Capacity / Revenue / COGS / Payroll / OPEX /
CAPEX / Depreciation / Working Capital / Tax-Zakat-VAT / Debt / Equity /
Income Statement / Balance Sheet / Cash Flow / FCFF / FCFE / KPIs /
Break-even / NPV-IRR / Scenarios / Sensitivity / Stress Tests / Sources.

## اختبارات الربط
Closing Cash = Opening Cash + CFO + CFI + CFF
Assets = Liabilities + Equity
Closing Debt = Opening Debt + Drawdowns - Principal
Closing PPE = Opening PPE + CAPEX - Disposals - Depreciation
Closing RE = Opening RE + Net Income - Dividends

## قواعد
- الإيراد يأتي من drivers وليس CAGR عام.
- الربح لا يساوي النقد.
- Bookings/Billings/Revenue/Collections منفصلة عندما يلزم.
- التمويل قبل/بعد الدين يعرض منفصلًا.
- لا NPV/IRR نهائي قبل اكتمال التدفق النقدي.
