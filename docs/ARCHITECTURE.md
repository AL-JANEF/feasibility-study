# Architecture

Feasibility Study separates method, evidence, mechanics and judgment.

- `SKILL.md` — thin conductor/state machine.
- `references/` — stage-specific methods, loaded only when needed.
- `templates/` — deterministic study skeleton.
- `feasibility_study/` — deterministic evidence, financial and decision-support code.
- `scripts/` — CLI and safe personal-skill installer.
- `tests/` — regression tests.

The agent researches and synthesizes. Deterministic code checks structure and calculates mechanical outputs.
Neither silently substitutes for the other.

## Boundary with JANEF Forge

JANEF Forge is engineering discipline for coding agents. Feasibility Study is business/investment
feasibility decision support. They can coexist but neither depends on the other.
