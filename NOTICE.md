# Feasibility Study — provenance and license boundary

Feasibility Study is an original implementation by AL-JANEF.

The design process reviewed public agent-skill repositories covering feasibility,
startup validation, market analysis, business planning, financial modeling, and
consulting-style problem solving. Their useful ideas and patterns were studied,
but Feasibility Study's wording, structure, code, schemas, gates, and decision
workflow were written independently.

Reviewed sources included:

- `dungnotnull/brainstorming-idea-to-project-deeply` — GPL-3.0. No code or text
  from this repository is incorporated. High-level concepts only informed the
  problem space.
- `ferdinandobons/startup-skill` — MIT.
- `trinity-ai-labs/market-skills` — MIT.
- `Musengimana/develop-a-business-plan-in-minutes` — MIT.
- `aapersh/consulting-strategy-problem-solving` — no repository license was
  exposed in reviewed metadata; no code/text was copied.
- `PJharwal/market-research-skill` — reviewed as a framework-oriented market
  research implementation.
- `duc01226/EasyPlatform/.claude/skills/business-evaluation` — reviewed as an
  evidence-gated business evaluation workflow.
